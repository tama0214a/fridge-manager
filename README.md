# 研究室冷蔵庫管理システム

研究室の共用冷蔵庫に「いつ・誰が・何を・どの冷蔵庫に入れ、いつ破棄したか」を記録・追跡するアプリです。研究室のWindows PCにインストールして、ブラウザで操作します。

## 主な機能

- **入庫登録** — 品名・数量・所有者・冷蔵庫・位置・入庫日・保管期限・メモを記録
- **出庫・破棄登録** — 破棄／使用のため取り出し／その他を、実施者・実施日つきで記録
- **期限アラート** — 期限切れは赤、期限間近（既定7日以内）は黄色で画面に表示
- **メール通知（オプション）** — 毎日決まった時刻に、期限切れ・期限間近アイテムの所有者へ自動メール。管理者へのまとめ通知つき
- **操作履歴** — 入庫・出庫・破棄・編集・削除・通知をすべて記録（監査証跡）
- **CSV出力** — 保管品一覧・履歴をExcelで開ける形式で出力
- **バックアップ** — ワンクリックでデータベースの控えを作成

データはすべてPC内の `data` フォルダ（SQLiteファイル）に保存されます。外部サーバーは使いません。

## インストール（研究室のWindows PC）

### 1. Pythonをインストールする（初回のみ）

1. https://www.python.org/downloads/ から最新のPython（3.10以上）をダウンロード
2. インストーラーの最初の画面で **「Add python.exe to PATH」に必ずチェック** を入れて「Install Now」
   - チェックを忘れても、python.orgのインストーラーなら付属の `py` ランチャーで動きます

### 2. アプリを配置する

`fridge-manager` フォルダごとPCにコピーします。置き場所は **`C:\fridge-manager`** のような浅くて同期対象でない場所を推奨します（OneDrive・Dropbox配下はデータベースの同期競合が起きうるので避けてください）。

### 3. セットアップ（初回のみ）

`setup.bat` をダブルクリック。必要なライブラリが自動インストールされ、「Setup complete.」と表示されたら完了です。

> プロキシ環境でインストールに失敗する場合は、情報基盤センターにpip用プロキシ設定を確認してください。

### 4. 起動する

`start.bat` をダブルクリック。黒いウィンドウが開いてサーバーが起動し、ブラウザで管理画面（ http://localhost:8341/ ）が自動的に開きます。**黒いウィンドウは閉じずに最小化**しておいてください（閉じるとアプリが止まります）。

### 5. 最初の設定

1. **マスタ管理** で冷蔵庫（名前・温度帯・場所）と研究者（氏名・メールアドレス）を登録
2. **設定** で標準保管日数・「期限間近」日数を必要に応じて調整
3. あとは各自が **入庫登録** から使い始められます

## Macで動かす場合

`start.command` をダブルクリックするだけです（初回は自動でセットアップが走ります。約1〜2分）。ブラウザで管理画面が自動的に開き、ターミナルのウィンドウを閉じるとアプリが停止します。バックグラウンドに残った場合は `stop.command` で停止できます。

- 必要なもの: `python3`（macOSの開発ツールまたは python.org 版）
- 実行環境（venv）はフォルダ内ではなく `~/.venvs/fridge-manager` に作られます（iCloud同期による肥大化・破損を避けるため）
- zipを別のMacで展開した場合、初回だけ「開発元が未確認」の警告が出ることがあります。その場合は `start.command` を右クリック →「開く」で起動してください
- **注意**: このフォルダをiCloud等で複数のMacと同期している場合、複数台で同時に起動しないでください（データベースが競合します）。本運用は研究室のWindows PC 1台で行うのが前提です

## 日常の使い方

| したいこと | 操作 |
|---|---|
| 冷蔵庫に物を入れた | 「＋ 入庫登録」→ 品名・自分の名前・冷蔵庫を選んで登録 |
| 物を捨てた・使い切った | 一覧かダッシュボードの「出庫・破棄」→ 種別と自分の名前を選ぶ |
| 期限切れがないか確認 | ダッシュボードを開く（赤＝期限切れ、黄＝間近） |
| 誰がいつ何をしたか調べる | 「履歴」で検索・CSV出力 |
| 登録内容を間違えた | 一覧の「編集」で修正。出庫・破棄の取り消しや削除もここから |

保管期限は入庫日基準のクイックボタン（+1週間〜+1年）か日付指定で設定でき、空欄なら標準日数が自動適用されます。長期保存品は「期限なし」にできます。

## メール通知の設定（オプション）

PCが起動していれば、毎日設定時刻（既定 09:00）に期限をチェックし、**期限切れ・期限間近アイテムの所有者**（マスタでメールアドレス登録済みの人）と**管理者**に自動メールを送ります。対象が残っている限り毎日再通知されます。時刻にPCが停止していた場合は、次にアプリが動いた時点で送信されます。

**設定手順（設定ページ）:**

1. 「期限切れ・期限間近のアイテムを毎日メールで自動通知する」にチェック
2. 通知時刻・管理者メールアドレスを入力
3. SMTP（送信サーバー）を入力して保存
4. 「テスト送信」で受信を確認 →「通知チェックを今すぐ実行」で本番動作を確認

**Gmailを使う場合**（研究室用のGoogleアカウントを推奨）:

- SMTPサーバー `smtp.gmail.com`、ポート `587`、暗号化 `STARTTLS`
- ユーザー名 = Gmailアドレス
- パスワードは通常のパスワードではなく **アプリパスワード**:
  Googleアカウント → セキュリティ → 2段階認証を有効化 → 「アプリパスワード」で16桁を発行し、それを入力

**大学のメールサーバーを使う場合**: 情報基盤センターにSMTPホスト名・ポート・認証方式を確認してください（学内送信専用サーバーなら暗号化「なし」・認証なしで動くこともあります）。

> 注意: SMTPパスワードは `data\config.json` に平文で保存されます。個人アカウントではなく研究室共用アカウントのアプリパスワードを使い、PC自体のログインを管理してください。

## PC起動時に自動で立ち上げる（推奨）

1. `Win + R` →「`shell:startup`」と入力してEnter（スタートアップフォルダが開く）
2. `start_hidden.vbs` を右クリック →「ショートカットの作成」→ できたショートカットをスタートアップフォルダに移動

これでサインイン時に黒いウィンドウなしで自動起動します。この方式ではブラウザは自動で開かないので、`http://localhost:8341/` をブラウザのお気に入りに登録しておいてください。停止したいときは `stop.bat` をダブルクリックします。

あわせてWindowsの **電源設定でスリープを「なし」** にしておくと、メール通知が毎日確実に動きます。

## 他のPC・スマホから見る（同じ研究室ネットワーク内）

1. 管理画面のあるPCで `Win + R` →「`cmd`」→ `ipconfig` と入力し、「IPv4 アドレス」（例 `192.168.1.23`）を確認
2. 他のPCのブラウザで `http://192.168.1.23:8341/` を開く
3. 初回起動時にWindowsファイアウォールの許可ダイアログが出たら「プライベートネットワーク」で許可
   （出なかった場合: ファイアウォール設定で受信規則としてTCPポート8341を許可）

> ログイン機能はありません。研究室内ネットワークだけで使い、外部公開はしないでください。

## データ管理

- 保存場所: `data\fridge.db`（SQLite 1ファイル）。設定は `data\config.json`
- バックアップ: 設定ページの「今すぐバックアップを作成」→ `data\backups\` に保存。`data` フォルダごと定期的にUSBメモリ等へコピーすれば完全な控えになります
- アプリの更新: `data` フォルダ**以外**のファイルを新版で上書きすれば、データはそのまま引き継がれます

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| `setup.bat` で「Python not found」 | 手順1でPythonをインストール（PATHチェック付き）して再実行 |
| 起動時「ポートが使用中」エラー | `data\config.json` の `"port": 8341` を `8342` などに変えて再起動 |
| ブラウザが開かない | 手動で `http://localhost:8341/` を開く |
| 他のPCから見えない | ファイアウォールでポート8341を許可。IPアドレスの変更（DHCP）にも注意 |
| メールが送れない | 設定ページの「テスト送信」のエラーメッセージと「メール送信ログ」を確認。Gmailはアプリパスワード必須 |
| 画面が崩れる | Microsoft Edge / Google Chrome の新しめのバージョンを使用 |

- 対応ブラウザ: Edge / Chrome / Firefox / Safari の近年版
