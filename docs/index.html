Setup Guide

🧊 研究室冷蔵庫管理システム
導入ガイド

共用冷蔵庫の「いつ・誰が・何を・どこに入れ、いつ破棄したか」を記録するアプリを、研究室のWindows PCにインストールする手順です。

Windows 10 / 11 Mac対応 所要 約10分 外部サーバー不使用
⬇️ fridge-manager.zip をダウンロード ソースコード（GitHub）

インストール（Windows）

研究室の共用PC 1台にインストールすれば、他のメンバーはブラウザで開くだけで使えます。

1

Pythonをインストール初回のみ

python.org/downloads から最新版（3.10以上）を入手し、インストーラー最初の画面で「Add python.exe to PATH」に必ずチェックしてから Install Now を押します。

2

アプリを配置

上のボタンからダウンロードしたzipを展開し、フォルダごと C:\fridge-manager にコピーします。OneDrive・Dropboxの同期フォルダ内は避けてください（データベースが同期競合を起こすことがあります）。

3

セットアップを実行初回のみ

setup.bat をダブルクリック。「Setup complete.」と出たら完了です。

4

起動

start.bat をダブルクリック。黒いウィンドウが開き、ブラウザで管理画面（http://localhost:8341/）が自動的に開きます。黒いウィンドウは閉じずに最小化してください。

5

最初の設定

画面上部のマスタ管理で、冷蔵庫（名前・温度帯・場所）と研究者（氏名・メールアドレス）を登録します。これで全員が「＋ 入庫登録」から使い始められます。

Macの場合は、展開したフォルダの start.command をダブルクリックするだけです（初回は自動セットアップ）。別のMacで「開発元が未確認」と出たら右クリック→「開く」で起動できます。

日常の使い方

操作はすべてブラウザ画面から。履歴が自動で残ります。

したいこと操作
物を入れた「＋ 入庫登録」→ 品名・自分の名前・冷蔵庫・位置（1〜3段 × 左右）を選ぶ。期限はクイックボタン（+1週間〜+1年）か「期限なし」
捨てた・使い切った一覧の「出庫・破棄」→ 種別(破棄／使用)と自分の名前を選ぶ
期限チェックダッシュボードを開く。赤＝期限切れ・黄＝期限間近
記録を調べる「履歴」で検索、CSV出力でExcelへ
間違えた一覧の「編集」から修正・取り消し・削除

メール通知を有効にする

オプション。毎日決まった時刻に、期限切れ・期限間近の所有者と管理者へ自動メールを送ります。

1

設定ページで「毎日メールで自動通知する」にチェックし、通知時刻と管理者アドレスを入力します。

2

SMTP情報を入力して保存します。Gmail（研究室共用アカウント推奨）の場合：サーバー smtp.gmail.com、ポート 587、暗号化 STARTTLS。

Gmailは「アプリパスワード」が必要です。 Googleアカウント → セキュリティ → 2段階認証を有効化 → アプリパスワードで16桁を発行し、それをパスワード欄に入力します。大学のメールサーバーを使う場合は情報基盤センターにSMTP設定を確認してください。
3

「テスト送信」で受信を確認し、「通知チェックを今すぐ実行」で本番の通知内容を確かめます。

通知はPCが起動している間だけ動きます。電源設定でスリープを「なし」にし、下の自動起動も設定しておくのがおすすめです。

あわせて設定しておくと便利

どちらも数分で終わります。

設定手順
PC起動時に自動起動 Win + R → shell:startup でスタートアップフォルダを開き、start_hidden.vbs のショートカットを入れる。以後はサインインと同時に画面なしで起動（ブラウザのお気に入りに http://localhost:8341/ を登録）。停止は stop.bat
他のPC・スマホから利用 管理PCで ipconfig を実行してIPv4アドレスを確認し、同じ研究室ネットワークの端末から http://（そのIP）:8341/ を開く。ファイアウォールの確認が出たら「プライベートネットワーク」で許可。メンバー側のインストールは不要です
バックアップ 設定ページの「今すぐバックアップを作成」。data フォルダごとUSBメモリ等へコピーすれば完全な控えに
ログイン機能はありません。研究室内ネットワークだけで使い、外部には公開しないでください。

うまくいかないとき

詳しくは同梱の README.md にも記載しています。

症状対処
Python not found手順1をやり直す（PATHチェックを忘れずに）
ポート使用中エラーdata\config.json の "port": 8341 を 8342 などに変えて再起動
メールが送れない設定ページの「テスト送信」のエラー表示と「メール送信ログ」を確認。Gmailはアプリパスワード必須
他のPCから見えないファイアウォールでTCPポート8341を許可。PCのIPアドレス変更にも注意
データはすべて管理PC内の data\fridge.db（SQLite）に保存されます。アプリ更新時は data フォルダ以外を新しいファイルで上書きしてください。
